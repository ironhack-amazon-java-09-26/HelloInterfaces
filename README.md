# Herencia e Interfaces en Java

**Herencia** → Entre dos clases hay una relación de evolución entre uno y otro

**Interface** → Cuando dos clases comparten el mismo comportamiento o una misma acción, pero son de origen diferente

Una clase puede heredar solo de una clase

Mientras que una clase puede implementar muchas interfaces
